# Changelog

## 1.0.0 (26 November 2026)

First official release.

- Find wishlist games shared by your Steam Family, or listed in PC Game Pass, Console Game
  Pass, PS Plus Game Catalog or PS Plus Classics.
- Select the matches to remove, one by one or all at once, and confirm before anything changes.
- Undo the latest removal.
- Credit and optional Ko-fi link in the panel.
- Browser extension tested on a real account in Microsoft Edge.
- Millennium plugin tested on a real account in the Steam desktop client.
- **Experimental:** the Decky Loader plugin has not been tested on a Steam Deck.
